# Security Policy

## Supported Versions

The following versions of the project are currently being supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

I take the security of our project seriously. If you find a security vulnerability, please do not disclose it publicly. Instead, please report it to ME via the following process:

1. **Email ME**: Send a detailed report to `mihlalimabovula@outlook.com`.
2. **Details to include**:
   - A description of the vulnerability.
   - Steps to reproduce the issue.
   - Potential impact of the vulnerability.
3. **Acknowledgment**: I will acknowledge your report within 48 hours and provide a timeline for a fix.

Thank you for helping ME keep this project secure!
